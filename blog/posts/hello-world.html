开博：为什么又搭了一个博客

域名、Pages、静态文件都齐了，这次把记录这件事固定下来。

之前不是没有地方写东西，但一直缺一个“写了就留在那里”的地方。社交平台的动态太碎，仓库的 README 又太正式。博客刚好在中间：可以慢慢写，写完也不会被时间线冲掉。

这次的选择

站点是纯静态 HTML，放在 xiguahahaha.github.io 仓库的 blog/ 目录下，由 Cloudflare Pages 发布到 gpgz.dpdns.org。原来的个人主页和隐私政策页面继续留在 GitHub Pages，两边互不干扰。

为什么不选动态博客？

因为要写的多半是配置笔记和代码片段，静态文件足够；也不想为了一个博客再维护数据库和后台。

打算怎么写

  • 一篇只讲一件事，标题尽量直白。
  • 配置类文章写完顺手记下“不能动什么”，省得下次自己踩坑。
  • 不追求更新频率，有东西值得记再发。

第一篇就到这里。后面会把这次域名接入 Pages 的过程整理出来。
